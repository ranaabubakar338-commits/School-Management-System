# School Management System (C++)

A console-based School Management System developed in C++ using Object-Oriented Programming (OOP). This project provides a simple interactive interface to manage student records, teacher information, and course assignments.

## Features

- **Student Management:** Enter student names, IDs, and marks.
- **Marks Validation:** Validate student marks within the range of 0 to 100.
- **Attendance Tracking:** Check attendance percentage and determine eligibility based on a 75% attendance threshold.
- **Teacher Management:** Store teacher information and assign subjects.
- **Course Management:** Create course records and assign teachers.
- **Interactive Menu:** Navigate through different management options using a simple menu-driven interface.

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance
- Encapsulation
- Standard Library (`iostream`, `string`)

## Concepts Demonstrated

- Class creation and object management
- Inheritance using the `Person` base class
- Data encapsulation with access specifiers
- Member functions
- Function overriding
- Conditional statements
- Loops and input handling

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/school-management-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd school-management-system
   ```

3. Compile the source code using a C++ compiler:

   ```bash
   g++ main.cpp -o school_management
   ```

4. Run the program:

   **Windows:**
   ```bash
   school_management.exe
   ```

   **Linux / macOS:**
   ```bash
   ./school_management
   ```

## Usage

After running the program, select an option from the menu:

1. Student: Enter student details, marks, and attendance.
2. Teacher: Enter teacher details and assign a subject.
3. Course: Enter course information and assign a teacher.
4. Exit: Close the application.

## Project Purpose

This project was developed to practice and demonstrate fundamental C++ programming and Object-Oriented Programming concepts through a practical school management application.
